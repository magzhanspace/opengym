# Наш форк openGym

Ветка `magjan` от тега `v1.4.5` (то, что сейчас крутится на gym.magjan.dev). `upstream` смотрит на
DuarteSantos8/openGym; вливать оттуда больше не планируем — режем под себя.

Лицензия AGPL-3.0: пока сервисом пользуемся только мы, никаких обязательств. `LICENSE` и `NOTICE.md`
(лицензия анимаций упражнений) не удаляем.

## Сколько тут всего

| Что | Объём |
|---|---|
| Фронтенд (React 19 + Vite), без тестов и переводов | ~110 тыс. строк |
| — из них `sheets.jsx` / `useStore.js` | 4 864 / 2 327 строк (ядро, трогать аккуратно) |
| Переводы, 25 языков | ~146 тыс. строк (по ~5 900 на язык) |
| Тесты фронтенда | ~900 файлов, ~128 тыс. строк |
| API (`node:http`, один `server.js` на 3 800 строк + модули) | ~23 тыс. строк, 137 тест-файлов |
| Каталог упражнений (`catalogue/`) | 268 МБ, из них анимации 215 МБ |

Вывод: переписывать с нуля нет смысла — логика тренировок (прогрессия, разминки, таймер,
синхронизация, офлайн) большая и рабочая. Режем форк.

## Что оставляем (ядро)

- Тренировка: запись подходов, **таймер отдыха**, цифры прошлой тренировки, прогрессия.
- Планы и рутины, неделя, история, базовая статистика и графики.
- Библиотека упражнений с анимациями.
- Импорт из Hevy/Strong (CSV), экспорт и бэкап (`Settings → Data & backup`).
- Вход по passkey, PWA (офлайн, «На экран Домой»), синхронизация между устройствами.

## Что режем

### 1. Бесплатно — ядро это не импортирует

| Что | Зачем было |
|---|---|
| `website/` | сайт opengym.ch |
| `helm/`, `kubernetes/`, `contrib/`, `cloudflare/` | другие способы деплоя |
| `fastlane/`, `.gitlab/`, `.gitlab-ci.yml`, `.github/` | публикация в сторы и CI апстрима |
| `watch-zepp/`, `frontend/garmin/` | часы Zepp и Garmin |
| `frontend/ios/`, `frontend/android/` + Capacitor | нативные приложения (**если остаёмся на PWA**) |

Строки — код без тестов (фронт по именам файлов, примерно; API точно). Тесты уходят вместе с кодом.

### 2б. Языки — самый большой и самый дешёвый кусок

- 23 из 25 пакетов интерфейса — около 135 тыс. строк.
- Названия и инструкции упражнений на этих языках: `catalogue/i18n` 27 МБ, `src/instr` 16 МБ,
  `src/exercise-names` 6 МБ. Сейчас сборка весит 42 МБ, почти всё — по чанку на язык.
- Оставляем `ru` и английский (он исходный, ключи переводов — английские строки).

### 3. Потом — дёшево, но не сейчас

- Языки (2б) — после модулей, иначе каждая вырезка правит 25 пакетов. Заодно поправить
  `check-locales`, который требует строку во всех пакетах.
- Чистка `sheets.jsx`, `useStore.js` и списков ключей синхронизации (`lib/sync-merge.js` ↔
  `api/sync-stamps.js`, их сверяет тест) — после того как уйдут модули.

## Подводные камни

- `api/coach/core` — не только AI. Там же стрики (`streak.js`), стартовые планы, библиотека рутин,
  валидация планов, справочник упражнений (`library.js`) — их импортируют фронт, тренеры и
  интеграции. Перед удалением Коуча эти файлы переезжают в `api/shared/`.
- `lib/coach-secrets.js` — на самом деле общее защищённое хранилище (им пользуются WebDAV,
  openNutrition, Cloudflare Access).
- Ключи `coach` в синхронизации меняются только парой (фронт + API) в одном коммите.

## Деплой

Сборка фронта в `web/Dockerfile` идёт на платформе сборщика, поэтому образы под `amd64` собираются
на Mac быстро: `docker buildx build --platform linux/amd64`, затем `docker save | ssh hermes docker load`.
На hermes в `/home/magzhan/apps/opengym` остаются `data/` и `.env`, меняются только образы в compose.
Перед первым своим деплоем — разовая копия `data/`.
